# Timeless-conventions term list. Read by scripts/validate-timeless.sh.
#
# One term per line: <extended-regex><TAB><category>. Terms are matched
# case-sensitively as whole words (bounded by non-word characters) in every
# scanned line: no section and no line is exempt. Escape dots.
# Longer terms are tried first, so "React Native" consumes before "React".
#
# What belongs here: proper names of frameworks, libraries, programming
# languages, API styles, products, services, vendors, and identifiers bound
# to one of them (env-var prefixes, config file names, hook and class names).
# The framework names none of them; the session picks the stack from the use
# case and records it in the project's own files. What does NOT belong here:
# open standards and formats (HTTP, JSON, OWASP, WCAG, ARIA, OAuth),
# regulations (HIPAA, GDPR, PCI), and the platforms a product ships to.
# Common English words that double as product names (Black, Square, Monday,
# Provider, Bootstrap, Go) are deliberately absent; they are caught by
# review, not by this list. The same goes for product names that are ordinary
# capitalized words at sentence start (Express, Relay, Remix, Cursor, Notion).
#
# Prefix and extension terms carry their own tail ("NEXT_PUBLIC[A-Z_]*",
# "[A-Za-z0-9_-]*\.tsx") because the word boundary treats "_" and letters
# as word characters: a bare "NEXT_PUBLIC" would never match
# NEXT_PUBLIC_SITE_CONFIG.
#
# Add a term when a review finds a name the list missed. Remove nothing
# because a name went out of fashion: the list only grows.
